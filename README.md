# ⚡️  Puzzle 🧩

A **fun and interactive web-based sliding puzzle game** featuring Pokémon images! Rearrange the puzzle tiles to complete the image, trigger a confetti celebration 🎉, and reveal the winning Pokémon background 🌟.

---

## 🕹 Features

- 🖼️ **3x3 sliding puzzle** with Pokémon images  
- 🎊 **Confetti animation** when you solve the puzzle  
- 🔄 **Reset button** to scramble and restart the puzzle  
- 📱 **Responsive design** for desktop, tablet, and mobile  
- 🌈 Fun Pokémon-themed background and winning overlay  

---

## 🎮 How to Play

1. Click on a puzzle tile adjacent to the blank tile to move it.  
2. Arrange all tiles in the correct order:

3. Once solved:  
   - 🎉 Enjoy the confetti animation  
   - 🏆 See the Pokémon winning image  
4. Click the **Poké Ball button** to reset the puzzle at any time 🔄  

---


## ⚡ Technologies Used

- **HTML5** – Structure  
- **CSS3** – Styling & responsiveness  
- **JavaScript** – Game logic  
- **[canvas-confetti](https://www.npmjs.com/package/canvas-confetti)** – Celebration animation 🎊
